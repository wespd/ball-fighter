# Spatium Ball

> An incremental survival clicker game built for the **Brackeys 2026.1 Game Jam**. 

🎮 **[Play the game on itch.io!](https://stormrun.itch.io/spatium-ball)**

## 📖 About the Project
*Spatium Ball* is an action-survival game where you fight off hordes of enemy balls by clicking, upgrading, and utilizing the physics of the arena. Developed under the time constraints of a major game jam, this project focuses heavily on satisfying 2D physics and engaging progression loops.

**My Role:** Lead Programmer and Game Designer  
**Teammate:** [Cloaked](https://cloaked11.itch.io/) (Art and Game Design)

## ✨ Key Features & Mechanics
* **Incremental Upgrade System:** A progressive shop/upgrade loop allowing players to scale their power and abilities to survive tougher waves.
* **Complex 2D Physics:** Engineered dynamic interactions including entity bouncing, collision damage, and unique environmental hazards like void peg absorption.
* **Cursor-Based Logic:** Programmed custom logic allowing players to deal damage directly by hovering or clicking, requiring active cursor tracking and input management.
* **Wave Survival:** Scaled difficulty across multiple levels as the player fights off increasingly chaotic hordes.

## 🛠️ Built With
* **Engine:** Godot Engine (v4.6)
* **Language:** GDScript
* **Version Control:** Git & GitHub

## 🚀 How to Run Locally
If you want to pull this repository and run it on your local machine:
1. Clone this repository: `git clone https://github.com/wespd/ball-fighter.git`
2. Open the **Godot Engine**.
3. Click **Import** and select the `project.godot` file from the cloned folder.
4. Press `F5` to run the project!
